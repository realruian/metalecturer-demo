# MetaLecturer

面向 AI 产品经理面试的线上数字教授课堂 Demo。以现有 HTML 原型和产品设定为基础，将课程浏览、互动课堂、课程资料与学习反馈串成一条可操作的体验流程。

交付目标：**界面完整、主要流程可操作、支持线上访问，并提供可阅读和运行的项目源码。**

**[在线体验](https://metalecturer-demo.vercel.app)** · 无需登录，点击首页导演课程卡片的「试看」开始。

## 界面预览

首页延续参考图的浅紫白底、蓝紫色品牌与电影感课程封面。课堂采用章节、互动舞台和问答三栏布局。

## 核心体验

| 能力         | 可以操作的内容                                                                      |
| ------------ | ----------------------------------------------------------------------------------- |
| 数字教授课堂 | 播放中文讲解、切换 5 个章节、调整播放进度与静音；移动机位观察越轴变化，完成课堂练习 |
| 课程知识库   | 搜索 5 份示例讲义、查看 10 个知识片段、阅读资料详情、下载 Markdown 讲义             |
| 随时问答     | 提交课程问题，检索相关知识片段并展示出处；点击引用回到对应章节                      |
| 学习数据回流 | 汇总实际听课时长、提问、实验、练习与笔记；切换时间范围，导出 CSV / JSON 记录        |

此外包含课程筛选与收藏、购物车选课演示、行业资讯阅读、创作社区示例、基于实际行为的四步学习路径，以及可编辑、排序、保存和导出的分镜工作台。购物车仅保存选课清单，不创建订单或发起支付；首页平台规模、课程价格和资讯为示例。

## 三分钟演示

1. **0:00–0:30｜进入课程**：在首页查看课程与分类，进入「导演思维与镜头语言」课堂。
2. **0:30–1:15｜听讲与动手**：点击播放中文讲解；调整机位，观察人物左右关系与轴线提示；完成一次练习。
3. **1:15–2:00｜提问与查证**：提问「为什么不能随意越轴？」，查看回答及课程依据，点击引用跳转章节；保存一条自己的笔记。
4. **2:00–2:30｜查看资料**：打开资源库，搜索「正反打」或「轴线」，查看并下载对应讲义。
5. **2:30–3:00｜查看反馈**：进入学习数据，查看刚才产生的记录并导出；学习路径会同步显示已体验的步骤。

有余量时，可进入创作中心，修改一条分镜并导出 Markdown 拍摄计划。学习数据中的「重置」经过确认后会清除个人体验记录，适合准备下一次演示。

## 真实实现与演示边界

- **问答采用本地课程资料检索**：服务端按关键词与同义词匹配示例讲义，返回资料片段和章节引用；未调用大语言模型，不是语义向量检索。未匹配到资料时明确提示没有找到依据。
- **数字教授采用示例形象与预生成语音**：中文音频使用 macOS Tingting 系统语音生成，播放器真实播放本地音频文件；未实现实时数字人视频或唇形生成。
- **个人数据来自实际操作**：听课、提问、实验、练习与笔记写入当前浏览器的 `localStorage`。刷新后可继续查看；不跨设备同步，没有账号后台。操作次数不等同于知识掌握度。
- **班级数据明确标为示例**：仅用于演示反馈界面，不代表真实用户规模或经营数据，也不会混入个人记录导出。
- **完整课堂聚焦一门微课**：其他课程卡片用于展示课程目录与详情，没有承诺提供完整教学内容。课程讲义为本 Demo 自编示例。
- **创作中心是分镜编辑器**：支持本地草稿和文件导出，不生成 AI 图片或视频。

本版本不需要模型 API Key、数据库或第三方付费服务。页面底部的「关于本次体验」也说明了主要实现边界。

## 本地运行

使用 Node.js 20.9 或更高版本及 npm；可使用 Node.js 22。安装版本由 `package-lock.json` 锁定。

```bash
npm ci
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。讲解音频需要点击播放按钮启动。

```bash
# 类型检查
npm run typecheck

# 课程检索、输入校验与引用测试
npm test

# 生产构建与运行
npm run build
npm start
```

## 技术与目录

当前使用 Next.js 16.3.5、React 19.3、TypeScript、Tailwind CSS 4 与页面独立 CSS；共享 Button / Dialog 为自定义组件，使用 Radix primitives、CVA 和类名工具，图标使用 Lucide。

```text
app/
  page.tsx                  应用入口
  globals.css               全局样式与平台界面
  api/chat/route.ts         课程资料检索接口
components/
  platform.tsx              课程目录、选课购物车与页面导航
  home.tsx                  对齐参考图的课程首页
  reference-art.tsx         立体分类图标与玻璃装饰
  discovery.tsx             示例资讯与创作社区
  classroom.tsx             互动课堂、播放、问答、笔记与练习
  knowledge.tsx             课程知识库
  analytics.tsx             学习数据与导出
  learning-path.tsx          四步学习路径
  studio.tsx                分镜工作台
  ui/                       共享 Button / Dialog
lib/
  courses.ts                示例课程目录
  knowledge.ts              讲义、检索与输入验证
  learning.ts               浏览器学习记录
public/
  assets/                   原型图片、生成封面与 SVG 课程封面
  media/                    预生成中文讲解音频
tests/
  knowledge.test.ts         检索及数据边界测试
```

原始 `MetaLecturer-Interactive-Demo 3(2).html` 保留在本地项目根目录，已通过 `.gitignore` 排除，不参与源码发布、应用运行和构建。项目未引入 AI Elements 或 OpenMAIC SDK。

## GitHub 与部署

- [线上体验](https://metalecturer-demo.vercel.app)
- [GitHub 仓库](https://github.com/realruian/metalecturer-demo)

将项目源码及 `package-lock.json` 上传到 GitHub 后，可以在 Vercel 中导入该仓库：

1. 项目根目录选择仓库根目录，框架选择 **Next.js**。
2. 安装命令使用 `npm ci`，构建命令使用 `npm run build`；输出目录保留框架默认值。
3. 仓库的 `vercel.json` 已明确指定 Next.js 框架。当前版本无需配置环境变量。部署后检查首页、课堂音频、`/api/chat` 问答、浏览器记录和文件导出。
4. 将已验证的部署地址放入仓库简介，并与仓库链接一同交付。

也可以在支持 Node.js 的环境执行 `npm run build` 和 `npm start`。由于问答使用 Next.js 服务端路由，部署时需要保留服务端能力。
